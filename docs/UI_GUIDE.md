# UI_GUIDE.md — Horizon (FTC 36596)

> Binding design reference. Deviate only with a stated reason.
> Generated by the frontend-design skill, 2026-08-16.

## 0. Direction & what we're opposed to

**Direction: editorial dusk.** A magazine laid over a night sky at the moment the
sun clears the horizon. Long-form prose that someone actually wrote, set in a
serif, on a deep plum-black ground, with the team's sunrise gradient used
sparingly as light rather than as decoration.

We are opposed to:

- **Startup-landing-page voice.** No three-word value props, no "Empowering the
  next generation of innovators." Horizon writes paragraphs. The sponsorship deck
  is the voice reference: complete sentences, concrete numbers, key phrases
  picked out in color.
- **The robotics-team template.** Not a stat band, not a 3-column icon-card grid,
  not a 100vh centered hero with two buttons.
- **Gradient-everything.** The sunrise gradient is the team's identity, so it is
  rationed: the logo, one hero element, hairline rules, and inline text
  highlights. Never a gradient headline, never a gradient card background.
- **Cool gray.** Every neutral is tinted toward the brand's plum. No slate.

## 2. Identity

- **Primary: Horizon orange `#F86A43`** (`brand-500`). Team-official, not chosen
  here. The full sunrise ramp is amber `#FFCB5C` → orange `#F86A43` → crimson
  `#B13848`. Owned, specific, nowhere near the indigo/violet default.
- **Neutral family: plum-tinted, derived from the official `#17061D`.** Two
  ramps — `night-*` for surfaces, `haze-*` for text. Every neutral carries a
  little of the brand's violet so nothing reads as generic gray.
- **Type pairing:**
  - **Display / UI: Jost** — geometric, Futura lineage. Chosen because the
    Horizon wordmark and the sun mark are built from circles and arcs; Jost is
    the same geometry. Used at 300–600.
  - **Prose: Newsreader** — optical-size serif. Every narrative paragraph on the
    site is set in it at 18–19px. This is the single biggest anti-slop decision
    on the project: a serif signals that a person wrote the words.
  - **Data: JetBrains Mono** — team number, dollar figures, tier prices, counts,
    timestamps. Always `tabular-nums`.
  - Inter and Space Grotesk are not used.
- **Signature: the horizon line.** A 1px sunrise-gradient rule that wipes in from
  the center as a section enters the viewport, and radial light that rises from
  the _bottom_ of a section rather than glowing from a corner. The hero carries a
  real sun disc clipped by that line. Nothing else on the site glows.

  Second signature, inherited from the team's own print materials: **inline
  color highlights inside prose** (`<Mark>`). Horizon's sponsorship deck picks
  out key phrases in amber and orange mid-sentence; the site does the same, so
  the pages read as the team's material rather than a web template.

## 4. Scales

- **Spacing** — 4px base, only `4 8 12 16 24 32 48 64 96 128`. Section rhythm is
  `py-24` mobile / `py-32` desktop, with `py-40` reserved for the hero.
- **Type** — 1.25 ratio. Display uses `clamp()` so the hero scales without a
  breakpoint jump. Prose is 18px/1.7 at ~68ch.
- **Radius** — `sm 4 · md 8 · lg 14 · xl 20 · 2xl 28 · full 9999`. Base is `lg`.
  Nesting rule: outer = inner + padding. Pills only on tags, badges, and buttons.
- **Shadows** — three elevations, each 2–3 layers, opacity ≤ 0.12 on dark plus a
  1px top highlight (`inset 0 1px 0 rgb(255 255 255 / 0.06)`) since shadows read
  weakly on a dark ground.
- **Easing** — `--ease-out-expo: cubic-bezier(0.16,1,0.3,1)` for reveals,
  `--ease-out-quart: cubic-bezier(0.25,1,0.5,1)` for hovers.

## 5. Motion

CSS only. Two mechanisms:

1. **`<Reveal>`** (`components/Reveal.tsx`, client) — one IntersectionObserver
   toggles a class; children translate up 16px and fade in over 700ms on
   `--ease-out-expo`, with an optional stagger delay. Fires once.
2. **Hover/press** — `transform` and `color` only, 150–200ms, `--ease-out-quart`.
   Never `opacity-80` as the whole hover state.

`prefers-reduced-motion: reduce` collapses every reveal to instant-visible and
disables the sun drift, in `globals.css`. Routine transitions stay under 300ms.

## 6. Component conventions

- **`<Prose>`** wraps narrative copy: Newsreader, 18px, 1.7, `max-w-[68ch]`,
  `text-wrap: pretty`.
- **`<Mark>`** highlights a phrase inside prose — `amber` (default), `orange`, or
  `crimson`. Semantic `<strong>` under the hood so it survives reader modes.
- **`<SectionHeading>`** — small Jost label in `brand-300` with open tracking,
  then the heading, then the horizon rule. No numbered `01/02/03` markers.
- **Buttons** — exactly one primary per screen (`bg-brand-500`, plum text, one
  tinted shadow). Secondary is a hairline ghost. Third level is a text link with
  an arrow that nudges 2px on hover.
- **Cards** — `night-850` on `night-950`, hairline `night-700` border, top
  highlight, `rounded-xl`. Never nested.
- **Tables** (tier matrix) — mono figures, `tabular-nums`, sticky first column on
  mobile via horizontal scroll inside `overflow-x-auto`.
- **Empty/placeholder image slots** — branded panel with the white mark at 25%
  opacity, the exact pixel dimensions the team should supply, and where the file
  goes. The site must look deliberate before the photos exist.

## 7. Anti-slop checklist for this project

```
☐ Primary is Horizon orange, never indigo/violet/blue-500
☐ Jost + Newsreader + JetBrains Mono; no Inter, no Space Grotesk
☐ Prose is serif, ≥18px, ≤68ch, real sentences — no three-word value props
☐ Neutrals are plum-tinted; no slate-* anywhere
☐ Gradient appears only in: logo, hero sun, hairline rules, <Mark>. Never a headline.
☐ No stat band, no 3-col icon-card grid, no 100vh centered hero
☐ One primary CTA per page, verb-specific ("Sponsor Horizon", not "Learn more")
☐ Atmosphere rises from the horizon line; no corner blobs
☐ Reveals under 300ms for UI, 700ms for one-time scroll entrances, reduced-motion honored
☐ Every unverified team fact is a marked placeholder, never invented
☐ Mobile checked at 375px; tier table scrolls, hero sun does not overflow
```
